# Instagram and Facebook asset specification

Final artwork must use the separately supplied, approved Panjab 117 logo. No logo file exists in this repository, so no substitute logo was created.

## Design system

- feed portrait: 1080 × 1350 px;
- safe area: 90 px sides, 110 px top/bottom;
- palette: navy `#0D2137`, ivory `#F8F4E9`, muted gold `#B08D46`/`#E6C56C`;
- typography: approved Gurmukhi/Devanagari-capable family; high contrast; no condensed display font for body copy;
- logo: approved original only, with clear space;
- no party colours, candidate images, ballot imagery, endorsements, participant counts or invented people.
